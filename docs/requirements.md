# 项目需求与验收口径

## 功能需求

1. 用户启动一次测量后，舵机触发弹簧锤完成主动敲击。
2. ESP32 采集压电传感器瞬态响应，可选用 IMU 作为辅助信号。
3. 端侧完成触发、截窗、FFT、物理特征提取和轻量模型推理。
4. OLED 输出“牢固 / 轻微松动 / 明显松动 / 测量无效”。

## 初始状态定义

- 牢固：标准试验板上完全拧紧。
- 轻微松动：初期以回松约 1/4 圈定义，最终以团队实测方案为准。
- 明显松动：初期以回松约 1 圈定义，最终以团队实测方案为准。
- 测量无效：敲击异常、安装异常、削顶、外部扰动或重复响应一致性不足。

## 量化指标

- 单次测量与输出时间 ≤ 5 s。
- 三档状态测试集准确率目标 ≥ 85%。
- 相同安装条件下主共振峰频率变异系数目标 ≤ 5%。
- 能识别并提示明显的无效测量。

## 未决事项

- ESP32 准确型号、固件框架和 ADC DMA 能力。
- 采样率、分析窗口和 512 点 FFT 是否适合实际频段。
- IMU 是否进入第一版分类模型。
- 最终使用螺纹圈数、扭矩还是两者定义状态。
